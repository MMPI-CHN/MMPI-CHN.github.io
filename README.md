# MMPI-CHN

一个于 2023 年 2 月上线的免费 MMPI-2 中文测试项目。全站为静态页面，不要求注册，
可以直接在浏览器中完成作答、计分和结果展示。

**在线使用** → <https://mmpi-chn.github.io/>

---

## 这是什么

- MMPI-2 全部 **567 题**，中英对照；也支持只作答前 370 题的短卷模式
- 输出原始分、K 校正分、T 分、两张人格剖析图、基础解释、关键题和原始选项
- 两张剖析图及 13 项基础解释表使用依据中国样本统计量换算的**近似中国 T 分**
- 完整技术表保留美国查表 T 分，便于专业人员复核整个计分链
- Chart.js 已随仓库发布，核心结果页不依赖绘图 CDN

## 这不是什么

**这不等同于正版 MMPI-2，也不能用于诊断。** 主要边界有三条：

1. **译文不同。** 本项目使用自行整理的中文译文，与正版《MMPI-2 中文简体字版》不同。
   本项目引用的中国常模由正版译文建立；题目是否等价无法确认，由此产生的偏差也无法量化。
2. **换算仍是近似。** 中国常模的完整原始分频数分布和原始分→T 分转换表未公开。
   本项目利用已出版的均值与标准差校正位置和离散度，仍沿用美国一致性 T 分的分布形状，
   因而不能冒充官方中国常模查表值。
3. **常模有年代边界。** 本项目使用的中国 MMPI-2 全国常模建立于 1990 年代，样本结构
   对标 1990 年第四次全国人口普查。截至 2026 年 9 月，我们没有查到正式出版并取代它的
   中国 MMPI-2 全国重常模；明尼苏达大学出版社的[当前翻译目录](https://www.upress.umn.edu/test-division/translations/)
   仍列出中文 MMPI-2，中文 MMPI-3 则仍在开发。因此它是本项目目前能确认的正式中国
   MMPI-2 依据，但无法校正此后三十余年的人群变化。

美国传统 567 题 MMPI-2 也仍以 1980 年代末采集的 2,600 人样本为基础。
2001 年手册修订、2003 年非性别计分方案及后续量表更新没有重新抽取当代全国样本；
[当前 MMPI-2 产品资料](https://www.pearsonassessments.com/en-us/Store/Professional-Assessments/Personality-%26-Biopsychosocial/Minnesota-Multiphasic-Personality-Inventory-2/p/100000461)
仍明确列出这套常模。2020 年发布的 [MMPI-3](https://www.upress.umn.edu/test-division/mmpi-3/)
采用了对标 2020 年人口统计的新常模，但它是 335 题、52 量表的另一套工具，不能直接替换
本站的 MMPI-2 计分。

容易混淆的一点是：美国**原始 MMPI** 的常模来自 1930 年代，并非 1980 年代；
1980 年代建立的是美国 MMPI-2 常模，以及中国第一版 MMPI 的本土化常模。
完整年代与来源见[常模、K 校正与 T 分科普](docs/科普-常模与T分.md#这些常模有多旧)。

结果可以拿去和专业人士讨论，但不要拿它当结论。

## 计分是怎么算的

```text
答案 → 原始分 → K 校正 → 美国 T 分（查表） → 基于中国样本统计量的近似 T 分
```

中国常模近似换算采用位置与离散度的双参数变换：

```text
T_中国 = 50 + (T_美国 − M_T) × 10 / S_T
```

`M_T`、`S_T` 取自 **Cheung, F. M., Song, W. Z., & Zhang, J. X. (1996).
The Chinese MMPI-2. In J. N. Butcher (Ed.), *International Adaptations of the MMPI-2*
(pp. 137–161)** 的表 6-3。该表给出中国全国常模样本（男 1106 / 女 1108，覆盖七大行政区）
在美国常模尺度上的均值与标准差。

换算模块覆盖 29 个量表并区分性别。第一张剖析图包含 13 个基础量表，第二张包含 15 个
内容量表；短卷只显示第一张。未收录中国参数或美国查表本身超出范围的量表会明确说明，
不会被伪装成正常数值。

## 2026 年 9 月的进一步贡献

这一轮工作从旧版的真实代码和数据出发，覆盖计分、常模、验证、交互、文档与发布工程。
下列每一项均已落入代码、测试或可复核文档；具体格值、证据等级、测试断言和提交索引见
[进一步贡献记录](docs/2026-09-贡献记录.md)。

1. **系统审计美国计分数据。** 扫描 147 组、约 5,000 格 T 分查表，检查单调性、邻域结构、
   线性段和男女表对应关系，不再把继承来的数据当作不可检查的黑箱。
2. **建立查表异常的证据分级。** 校正 9 处高度可疑的人工转录异常，同时保留高／中置信度、
   候选值和未决项，没有把推断写成官方原表已经逐格认证。
3. **建立可追溯的中国常模模块。** 将 29 个量表 × 男女的出版参数独立成数据模块，提供
   正向换算、逆向参考线、边界钳位和缺失数据语义。
4. **用逐量表、分性别换算取代全局 `−8`。** 消除“达到阈值才减 8”造成的跳变和分数倒退，
   也避免 K、Mf 男、Ma 女等量表方向相反时仍被统一减分。
5. **补齐长短卷与性别路径。** 短卷真正只读前 370 题，不再制造 197 个伪未答项；
   不适用于短卷的内容量表和完整 VRIN/TRIN 不再伪装成可计算。Mf 按所选性别查表并进入结果。
6. **统一图、表和解释的分数口径。** 两张剖析图均改画近似中国 T 分；主结果保留一张
   13 项基础解释表，完整技术表继续保留原始分、K 校正分与美国查表 T 分。
7. **明确异常与边界。** 区分“美国查表超范围”“没有中国常模参数”和普通数值；阻止
   `undefined`、`NaN` 或伪造的 0 混入图表；临床参考线只用于适合的量表。
8. **建立多层回归体系。** 形成 50 项 Node 计分／渲染回归、13 项数值检查、43 项真实浏览器
   检查及快照工具，覆盖男女、长短卷、空答、随机答卷、Mf、K 校正、图表点和重复提交。
9. **用出版样本和实际报告交叉核对。** 使用三个已出版样本共 174 格汇总数据、手册独立表格
   和两份实际结果 PDF 检查完整链路，同时明确这些证据不能证明个人分数已达到官方精度。
10. **清理重算与调试行为。** 重复计分会销毁旧图并替换旧报告；随机模拟改为每题一次抽样并
    覆盖旧选择；发布页面不再暴露调试按钮。
11. **移除绘图网络单点。** 将 Chart.js 2.9.4 和许可证纳入仓库，CDN 失效时仍可正常绘图。
12. **改进作答交互。** 将“是／否”改为更贴合题意的“符合／不符合”，扩大整块可点击区域，
    增加 hover、选中和键盘焦点状态，补充否定句作答说明，并订正已经确认的解释文字笔误。
13. **重组结果页信息层级。** 调整图表、参考提示、基础解释、技术明细和原始选项的顺序，
    改善列宽、长文本行宽、链接、换行和颜色；移除重复的美国解释表与个人页技术对照表。
14. **建立公开的研究文档。** 新增完整版探索纪要、TLDR、常模科普和 PDF 数据核验，记录
    来源、公式、验证、走过的弯路、证据边界和后续路线，而不只给出一份不可解释的代码结果。
15. **增强发布与可回滚性。** 将改动前版本完整归档到 `legacy/` 并标记 `v1-legacy`；加入
    `.nojekyll`、`robots.txt`、404 页面和 sitemap，在保留既有 URL 的前提下改善发布与 SEO。
16. **补齐来源与协作记录。** 梳理 Kevin Timmerman、AstralLing 与本项目的代码血缘，
    并通过文档及 Git 提交 trailer 记录 Claude 与 Codex 的实际参与。

## 开发与验证

```bash
node test/run-node.js      # 计分与结果渲染回归
node test/accuracy.js      # 出版汇总数据与数值链路检查
node test/snapshot.js 0 F  # 导出结果页快照：0男/1女，作答 T/F
```

浏览器回归需通过本地 HTTP 服务打开 `test/browser-check.html`。它检查真实页面、仓库内的
Chart.js、随机填答、长短卷和重复提交，不会发送答卷。任何计分层改动都应同时运行 Node 与
浏览器检查；各项验证能证明什么、不能证明什么，见[数据核验](docs/数据核验-2026-09-22.md)。

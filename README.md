# MMPI-CHN

国内第一个公开上线的免费 MMPI-2 中文测试（2023 年 2 月上线），纯静态页面，无后端。

**在线使用** → <https://mmpi-chn.github.io/>

---

## 这是什么

- MMPI-2 全部 **567 题**，中英对照，全题中文翻译
- 输出：原始分、T 分、人格剖析图、基础解析
- 两张人格剖析图及基础量表解释表显示依据中国样本统计量换算的**近似 T 分**；完整技术分数表保留原始分和美国查表 T 分
- 近似换算不能替代官方中国常模查表，也不能据此确认诊断界限

## 这不是什么

**这不等同于正版 MMPI-2，不能用于诊断。** 三个具体原因：

1. **译文不同。** 本项目的中文译文是自行翻译的，与正版《MMPI-2 中文简体字版》不同。
   而计分所依据的中国常模是用正版译文建立的 —— 常模能迁移的前提是题目等价，
   这一条我们无法满足，也无法量化偏差。
2. **常模只有位置与离散度。** 中国常模的完整原始分频数分布未公开。我们校正了分布的
   位置与离散度，仍沿用美国计分变换，未验证中国分布形状或个人分数误差。
3. **常模采样于 1990 年代。** 对标的是 1990 年第四次全国人口普查。它校正的是
   "1990 年代的中美差异"，不校正此后中国人群内部三十多年的变化。

结果可以拿去和专业人士讨论，不要拿它当结论。

## 计分是怎么算的

```
答案 → 原始分 → K 校正 → 美国 T 分（查表） → 基于中国样本统计量的近似 T 分
```

**中国常模换算**采用位置 + 离散度两参数仿射变换：

```
T_中国 = 50 + (T_美国 − M_T) × 10 / S_T
```

`M_T`、`S_T` 取自 **Cheung, F. M., Song, W. Z., & Zhang, J. X. (1996). The Chinese MMPI-2.
In J. N. Butcher (Ed.), *International Adaptations of the MMPI-2* (pp. 137-161)** 表 6-3 ——
该表给出中国全国常模样本（男 1106 / 女 1108，覆盖七大行政区，对标全国人口统计）
在美国常模尺度上的均值与标准差。两个参数直接取自已出版的样本统计量；最终个人分数仍是近似值。

换算模块覆盖29个量表。第一张剖析图包含13个基础量表，第二张包含15个内容量表，均使用各量表按性别换算后的近似中国 T 分；短卷不显示内容量表图。
完整技术分数表仍保留原始分、K 校正分和美国查表 T 分，其中未收录中国常模参数的量表不做中国分数换算。

**2026-09-22复核：[两份测试PDF的数据核验](docs/数据核验-2026-09-22.md)。** 页面显示分数和基础解释；
按作者要求移除了额外的答卷检查框。分数呈现不等于答卷效度已确认。

结果区在剖析图下先给出换算说明、“结果仅供参考”提示和13个基础量表的“中国常模近似T分／基础解释”表，再给出全量表技术明细（原始分及美国查表T分）和关键题表；原始选项列在最后，限制文字宽度以便阅读。
基础解释保留项目作者此前参考张建新主编《MMPI-2中文简体字版使用手册》手工录入的阈值与文字：
本轮只以新的近似中国T分替代旧版有条件减8分的结果，再沿用原来的三档选档规则，没有逐量表重建或逐档审定解释。
这不等于解释文字或个人分数已用中国样本独立验证。旧版另有一张美国T分解释表，并以达到阈值才减8分的方式生成第二张表；
现在不再展示重复的美国13项解释表，也不在结果页展示60分换算对照表（技术数据见[探索纪要-TLDR.md](docs/探索纪要-TLDR.md)）。

换算的推导、验证与局限：**[docs/探索纪要-TLDR.md](docs/探索纪要-TLDR.md)**（三分钟）

## 2026 年 9 月这次修了什么

作者在 2023 年的 README 里写过一句：*"前提是我用的那个哥的代码算一致性 T 分没算错"*。
核对发现9处疑似转录异常，已按邻域规律等证据修补；其中部分取值仍需原始出版表逐格确认。
现有测试支持局部数值与样本汇总数据的一致性，不能证明整张表及逐题计分键均已获官方验证。

| 修复 | 影响 |
|---|---|
| 9 处查表数值勘误 | 最严重两处：Sc 男某分段**偏低 37 个 T 分**、Mt 男两格**偏低 60 个 T 分**（把高分读成地板分） |
| Mf 性别下标写死为女性条目 | 潜伏缺陷。两张结果表原本都有 `if(i===7) continue` 跳过 Mf，两张剖析图又各自用对了下标，所以**改动前对用户无可见影响**。现已修正下标，并让 Mf 进入中国常模表 |
| 长短卷开关失效 | `longform` 变量从未被更新，选"短卷"会产生 **197 个未答项**，整张剖析图作废 |
| −8 全局修正 → 逐量表换算 | −8 在各量表上误差达 ±12 分，且 K / Mf(男) / Ma(女) **方向是反的** |
| 修正的有条件触发 | 原逻辑造成不连续：**原始分更高的人可能报出更低的 T 分** |
| T 分未钳位 | 现钳位于 [30, 120] |

旧版本完整保留在 **[`legacy/`](legacy/)**，线上可直接访问 <https://mmpi-chn.github.io/legacy/>，
一个字节都没改。git tag `v1-legacy` 标记了改动前的完整状态。

## 开发

```bash
node test/run-node.js      # 回归测试，含空答、随机答卷和PDF数值核验
node test/accuracy.js      # 数值准确性检验（13 项）—— 算出来的数对不对
node test/snapshot.js 0 F  # 导出结果页渲染快照（性别 0男/1女，作答 T/F）
```

Cheung表6-3的58格检查比较“原始分均值的查表值”与“样本T分均值”，
当前差值中位数0.60、最大2.0。非线性变换下两者并不严格相等，差值不能解释为个人T分误差。
另有两个香港样本的汇总检查，也不是对官方中国个人分数的独立验证。

浏览器回归：用本地HTTP服务打开 `test/browser-check.html`，检查真实页面和仓库内的Chart.js 2.9.4、
随机填答、长短卷、重复提交清理。该页面不发送答卷。

改动计分层之后**必须**跑一遍测试。

# 两份测试PDF的数据核验

结论：计分实现比旧版稳健，分性别、分量表的换算比有条件减8分有依据。但不能据此声称个人心理测量准确性已经验证，不能把近似换算标成官方中国常模T分。

本次读取交接文档、当前代码、`legacy/`、两份测试PDF，以及Cheung等1996年原书表6-3（PDF181页、书页145）和书页142。绘图按白色曲线、深色背景的现有设计处理，没有把打印中的白色曲线误判为未绘制。

## 1. 随机PDF的数字是否算对

旧版列按`legacy`中各量表自己的触发条件计算，并非一律减8。本例没有命中那9个查表修补点，变化主要来自常模近似换算。以D为例，`50+(68-62.8)*10/10=55.2`，显示55；K为`50+(62-47.3)*10/11.2≈63.125`，显示63。新方法并非统一降低分数。

F原始分29超过本项目男性美国表最高可查的28，无法由该表得到T分；不能把“没有查表值”硬填成120，再据此声称准确。

这次没有从图像型PDF完整恢复567个原始选项，因而本检查的起点是PDF记录的量表原始分，**不是逐题计分键的独立验证**。测试夹具只保存上表的数值，不收录PDF或书页。

## 2. 空答和随机答卷暴露的真实问题

`测试1.pdf`有567个未答。原版仍把原始分0送入查表，得到L=35、F=36，再换算成30，并给出“测试结果是可接受的”等文字。低原始分来自没回答，不能当成低症状。按作者要求，页面保留原有分数与解释，不再额外插入答卷检查框。

`测试2.pdf`中VRIN原始分14、美国T=84，TRIN原始分7、T=64F。Cheung等原书142页记录的中文研究筛查界限为VRIN原始分大于13、TRIN小于6或大于13。这份随机答卷触发VRIN界限。页面仍显示原有结果和人格解释；不能因换算后某些分数降低就称其更符合受测者。

现有计分路径仅在VRIN/TRIN题对不完整时避免把部分得分当作完整效度分数，未实现完整临床效度判断：

- 页面不另外显示答卷检查框，分数和解释照常展示。2021中文手册第二章第三节曾以未答不超过30题作为常模筛选条件；本站当前并未用该条件拦截展示。
- 不完整题对和短卷不伪装成正常完整VRIN/TRIN分数；原始分界限仅作为文献背景，并未用于页面筛查。
- 仍缺ICH等完整效度审查，少量漏答的量表级影响亦未完整处理；页面展示不代表答卷有效。
- 结果文字仍显示。13个基础量表只保留近似中国T分与一份基础解释。解释继续使用项目作者此前参考张建新手册手工录入的阈值、三档选档规则及原文字；本轮替换旧版有条件减8分所得数值，没有逐档重建或审定解释。近似个人分数和解释结论均未经独立验证。

关于先评估效度再解释实质性量表，也可参照[明尼苏达大学出版社MMPI-2效度培训材料，由Pearson提供](https://www.pearsonclinical.in/content/dam/school/global/clinical/us/assets/mmpi-2/interpretation-of-mmpi-2-validity-scales.pdf)。

## 3. 哪些“更准”有证据，哪些没有

已确认：新版消除了旧版在阈值处突然减8导致的分数倒退；表6-3的29组男女常模参数与原书相符；分性别的K校正、查表、近似变换在本例一致；短卷开关和相关量表适用性得到修复。

需要降低原有文档的断言强度：

1. 9个查表修补并非全部经过官方原表逐格比对。代码自身标明部分为medium置信度，例如A女性某格有78/79候选。本轮未擅自替换这些值；自检通过只说明修补仍在，不能证明候选值已获官方确认。
2. 用原始分均值查表与样本T分均值比较，是汇总数据一致性检查。非线性函数满足一般的`f(E[X]) != E[f(X)]`，0.60至3.14的差值不能称为个人计分误差。
3. 香港两组样本没有官方中国T分真值；落入宽泛合理区间不是“准确率提高”的外部验证。
4. 将同一表中的均值送入自身公式得到50、标准差对应10，是定义自洽。取整和30至120截断之后，连这两个矩也不必精确保持。
5. 本项目译文不同、常模年代久、缺少官方中国原始分转换表或逐人配对数据，仍无法量化个体误差。参数源自出版物不意味着输出是精确值。

出版社的[翻译与本土化说明](https://www.upress.umn.edu/test-division/translations/)列出的工作还包括信效度、标准误和逐量表原始分到T分转换表；两参数近似不能取代这些验证。

## 4. 本轮实现与后续

- 修正随机按钮逐个radio独立抽样的问题，改为每题抽一次T/F，覆盖旧选择并避免漏答。
- 短卷不计算依赖371题之后项目的内容量表或附加量表，完整VRIN/TRIN标为不可计算；文本入口也忽略短卷之外的答案。
- 另一性别的Mf条目不再被误报为分数过高/过低。
- 近似分数明确标注；60分不再泛用于L/F/K、Mf、Si的红色临床提示；内部比较参考线使用未取整值，技术对照表仅保留在文档中。
- 重算时销毁旧Chart实例并替换旧报告，空答也照常输出本次报告与图表。
- 原始量表大表和13项近似中国T分表中的Mf按所选性别各择一条显示，避免另一性别空计分表造成错误行。
- 移除结果页顶部的答卷检查框、重复的美国13项解释表及60分技术对照表。两张剖析图分别以基础量表和内容量表的近似中国T分绘制；全量表技术明细仍保留美国查表T分，不把未收录中国常模参数的量表强行换算。图下先呈现换算说明、红色参考提示和13项基础解释表，再呈现全量表及关键题技术明细，最后是限宽的原始选项；说明原文不缩短，说明及文档链接用蓝色。
- `MMPI-1-test.html`约208行的模拟作答按钮为作者调试入口；发布版本中已注释。
- 修复`legacy/`引用，并忽略本地测试PDF和临时提取图片；旧版文件保持原样。

发布定位应为“保留局限说明的开源近似计分工具”，不宜写“已验证达到官方MMPI-2准确度”。下一阶段可以做界面整理和发布准备；不需要为了UI工作等待不可得的官方数据，但也不能在界面中消除上述区别。尚未合并main或推送。
